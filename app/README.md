# Мок-данные демо-режима

`ios/` — JSON-ответы API, `pages/` — страницы для WebView, `src/` — картинки.
Приложение в демо-режиме читает их с `https://jolgo.ru/app/...`.

В моках не должно быть упоминаний «Газпромнефть», «ГПН», «Опти», `gpnbonus.ru`.
Все ссылки — только на `jolgo.ru` или `jolgo.kg`, включая картинки и документы.

## Локальная проверка в Proxyman до публикации

Чтобы приложение брало моки из этого каталога, а не с боевого сервера нужно добавить локальное правило 
с **URL:** `https://jolgo.ru/*`, **Map To** указвать на корень *директории* склонированного репозитория.

Домен `jolgo.ru` должен быть в SSL Proxying, а на устройстве/симуляторе установлен сертификат Proxyman.
